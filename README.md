# Hexa — Hexagon Pixel Art

A small React + Vite app for drawing pixel art on a clickable honeycomb grid.

## Features
- Click hexagons to paint them with the selected color
- Built-in palette and custom color picker
- Eraser, fill-all, clear-canvas, and undo
- Adjustable row and column counts
- Toggle hexagon outlines
- Export your art as a PNG

## Run locally
Requires Node.js 18+.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173).

To create a production build:

```bash
npm run build
```
